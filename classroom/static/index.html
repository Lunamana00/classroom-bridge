연결 전에 확인하세요

01

HTTPS 주소로 연결

배포 서버의 HTTPS MCP 주소를 클라이언트에 추가하세요. Google 로그인 후 연결 권한을 승인하면 됩니다. 로컬 주소는 같은 컴퓨터에서만 사용할 수 있어요.

02

OpenAI API로 판단

서버의 .env.local에 OPEN_API_KEY를 설정하세요. CLASSROOM_MODE=auto는 키가 있으면 gpt-6-luna를 사용하고, 키가 없으면 데모 검색을 사용합니다. codex 모드는 gpt-6-luna, jev 모드는 jev-1.14.0을 요청하며 해당 모델의 OpenAI API 접근 권한이 필요합니다. 변경 후 서버를 재시작하세요. API 키는 서버에만 보관합니다.

03

교수 도구는 교수에게

웹에서는 Google 로그인과 수업별 교수·학생 권한을 검사합니다. MCP 서버를 추가하면 같은 Google 계정으로 로그인하고 연결 권한을 승인합니다. 교수 도구는 담당 교수의 수업에만 접근하며 AI 연결 관리에서 언제든 해제할 수 있습니다.
