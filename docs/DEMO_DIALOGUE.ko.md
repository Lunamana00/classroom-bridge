# CS231n 2026 데모 대사집

이 문장은 실제 교수·학생이 AI에 말할 대사다. 수업은 **CS231n 2026**, 오늘 다룬 단원은 **역전파**로 설정한다. 전체 촬영 순서와 화면 동작은 [촬영 시나리오](DEMO_SCENARIO.ko.md)를 따른다. 학생 질문 장면은 해당 단원의 핵심 개념 추출과 교수의 웹 승인을 마친 뒤 진행한다.

## 교수

### 수업 자료 확인

> CS231n 2026 수업을 같이 준비해 보자. 어떤 자료들이 들어 있는지 간단히 정리해 줄래?

코드 원문을 첨부하거나 붙여 넣은 뒤:

> 이 코드도 우리 수업 자료에 넣어줘. 원문 그대로 보관해 줘.

### 자료에서 정리된 핵심 개념 확인

> 이 자료에서 찾은 핵심 개념들을 보여줄래? 원문도 함께 확인하고 싶어.

이전에 등록한 자료에 추출 결과가 없을 때:

> 전에 올린 역전파 복습 자료도 핵심 개념을 정리해 줘.

추출을 마친 뒤 개념과 출처를 읽고:

> 이 설명은 학생들이 헷갈릴 수 있겠네. 검토 화면에서 표현을 조금 다듬을게.

실제로 같은 개념의 통합 제안이 있을 때:

> 이 두 설명은 같은 연쇄법칙을 말하는 것 같아. 원문 근거를 같이 볼까?

교수는 웹의 **핵심 개념** 화면에서 초안을 수정하고, 원문과 통합 대상을 확인한 뒤 직접 승인한다. 필요 없는 초안은 제외한다. 이 승인은 이후 퀴즈를 학생에게 배포하는 승인과 별개다. 개념 추출이 완료됐다는 이유만으로 승인된 것으로 설명하지 않는다.

### 오늘 수업의 확인 퀴즈

> 오늘은 역전파를 설명했어. 학생들이 핵심을 이해했는지 확인할 짧은 퀴즈를 만들어 줄래? 객관식과 단답형을 섞어서 우선 보여줘.

> 정답과 해설도 같이 보자. 이 문제들이 오늘 설명한 내용과 잘 맞는지 확인해 줘.

교수가 실제 문항·정답·근거를 읽고 사용하기로 결정한 뒤:

> 좋아, 이대로 학생들에게 내줘.

### 학생들의 이해 확인

> 학생들이 오늘 수업을 잘 이해하고 있나?

> 특히 어디에서 많이 막히는 것 같아? 그렇게 본 이유도 같이 알려줘.

### 다음 수업 준비

> 다음 수업에 추가로 설명하면 좋을 부분은?

> 그중 가장 필요한 부분으로 5분 정도의 보충 설명을 준비해 줘. 칠판에서 같이 풀 쉬운 계산 예시도 하나 넣어줘.

### 시험 준비

> 이 수업에서 배운 내용을 고르게 확인할 수 있게 확인 시험 6문제를 만들어 줘. 쉬운 문제와 생각이 필요한 문제를 섞고, 정답과 해설도 같이 보여줘.

> 역전파에만 치우치지 않게 이미지 분류, CNN, Attention 내용도 함께 확인할 수 있으면 좋겠어.

## 학생

### 오늘 배운 내용 질문

> CS231n 2026에서 배운 역전파가 아직 헷갈려. upstream gradient와 local gradient를 왜 곱하는지 계산 예시로 설명해 줘.

AI가 찾은 개념과 선택 이유, 실제 원문 출처를 확인한 뒤:

> 연쇄법칙하고 ReLU의 미분은 역전파에서 어떻게 연결되는 거야? 두 개념을 같이 설명해 줘.

선택된 개념이 여러 개면 각각의 역할을 확인한다. 개념 관련성 점수를 계산·증명의 정확성이나 정답 확률로 설명하지 않는다.

실제로 제시된 문항을 읽고 고른 답을 말한다. 아래 기호는 그 문항에서 선택한 값으로 바꾼다.

> 내 답은 A야.

### 다시 풀기

> 아까 틀린 개념을 다시 확인해 보고 싶어. 비슷한 내용을 한 번 더 풀어 볼래.

> 지금까지 내가 푼 결과를 보여줘. 처음에 틀린 것과 다시 풀어서 맞힌 것을 구분해서 알려줘.

### 다른 단원과 코드 질문

> CNN에서 max pooling도 학습되는 파라미터가 있나요?

> Transformer의 self-attention은 입력 안에서 어떤 정보를 섞는 건가요? 수업 자료로 설명해 주세요.

해당 코드 원문을 함께 보며:

> 이 코드에서 ReLU를 지난 뒤 음수 입력의 기울기를 0으로 만드는 이유가 뭐야?

### 자료에 없는 질문

> 다음 시험은 언제, 어느 강의실에서 봐?

AI가 답을 위한 정보가 없다고 알려 주는 모습을 그대로 보여 준다. 승인 개념이 아예 없어 나오는 ‘개념 준비 필요’ 안내와, 개념은 준비됐지만 이 질문에 답할 근거가 없는 경우를 구분한다.

## 촬영 순서 메모

자료 등록 → 개념 추출 상태 확인 → 교수의 웹 검토·수정·승인 → 퀴즈 준비·배포 승인 → 학생 질문·선택된 개념·원문 확인 → 퀴즈 응답 → 교수 분석 순서로 진행한다. 이 메모는 읽을 대사가 아니다. CNN·Transformer 삽입 컷도 해당 개념이 원문 근거와 함께 검토·승인되어 있는지 먼저 확인한다.
